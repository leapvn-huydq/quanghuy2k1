# How to list this project on a CV (English)

## Preferred title

**Personal Project - Booking & Payment QA Automation Lab**

**Role:** Project owner / QA engineer  
**Tech stack:** Node.js, JavaScript, Playwright, REST API testing, GitHub Actions, Cursor, Claude Code, MCP-based test workflow design  
**Scope:** Independent fictional application with mock booking and payment flows

### CV-ready bullets (concise)

- Built an independent booking/payment mock application and a QA automation portfolio, covering test planning, business rules, traceability, API tests, UI test scripts and execution reports.
- Implemented and verified **55 automated API/domain test cases** for booking validation, inventory, payment webhooks, HMAC signatures, idempotency, state transitions and simulated partner failures.
- Authored **8 Playwright UI test scripts** to validate booking and payment journeys; separated browser checks from API regression for easier CI execution and reporting.
- Documented test scenarios, detailed test cases, defect templates, release-readiness checklists and a GitHub Actions workflow; prepared reusable Cursor rules/skills and Claude Code guidance for human-reviewed QA work.

**Important accuracy note:** The API/domain cases were executed successfully; the browser scripts were authored but could not be verified in the restricted working environment. Do not claim an independently verified end-to-end browser pass until a successful Playwright run is available.
